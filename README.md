# showticket-support

좌석 시야·창가 시야·라커룸 앱의 지원 페이지와 개인정보 처리방침은 gowoobro.com 으로 옮겼습니다.

| 앱 | 지원 | 개인정보 처리방침 |
|---|---|---|
| 좌석 시야 | https://gowoobro.com/ko/app/24 | https://gowoobro.com/ko/app/24/privacy |
| 창가 시야 | https://gowoobro.com/ko/app/25 | https://gowoobro.com/ko/app/25/privacy |
| 라커룸 | https://gowoobro.com/ko/app/26 | https://gowoobro.com/ko/app/26/privacy |

이 저장소의 GitHub Pages(https://kobums.github.io/showticket-support/)는 예전 주소로 들어온 사람을 새 주소로 보내는 역할만 합니다. 넘겨주는 페이지는 `python3 tools/build.py`로 만듭니다.
